# 我的小库存（私人精简版）

一个**纯前端、零后端**的个人库存管理网页应用：物品档案 + 库存批次 + 购物篮，支持库存不足提醒与批次过期提醒。所有数据保存在**你自己的浏览器本地**（localStorage），不上传任何服务器。

依据 PRD《我的小库存 V3.0》实现。

## 功能

- **物品档案（Item Master）**：名称、单位、默认阈值、默认补货数量、备注；一个物品只建一次档案。
- **库存批次（Batches）**：同一物品可有多批次，各自数量与过期日期；主页按物品聚合显示总库存，点进去看批次明细。
- **状态标签**：正常 / 库存不足 / 有临期批次 / 有已过期批次。
- **快捷操作**：`−1` 自动消耗最早过期的批次；低于阈值弹出补货询问。
- **购物篮**：模拟购物归来，多件物品一次录入，确认后每行生成一个独立批次（草稿保留）。
- **提醒中心**：只显示**当前未解决**的提醒——标记已读即删除；问题解决（补货到位、批次用完/清理）自动删除或实时更新数量；点「立即检查」可重新核对。
- **数据导入导出**：CSV 备份与恢复，同名自动归入同一档案。
- **可安装**：支持添加到 iPhone/Android 主屏幕，离线可用（Service Worker 缓存）。

## 文件结构

```
index.html              应用本体（单文件，含全部界面与逻辑）
manifest.webmanifest    PWA 清单（图标、名称、独立窗口）
sw.js                   Service Worker（离线缓存）
icon-192.png
icon-512.png
apple-touch-icon.png    应用图标（不要改名或移动，需与其他文件同一层）
.nojekyll               让 GitHub Pages 原样发布静态文件
```

## 部署到 GitHub Pages（网页版操作，最省事）

1. 登录 GitHub → 右上角 `+` → **New repository**。
2. 仓库名填 `xiaokucun`（随意），可见性选 **Public**（免费 Pages 需要公开仓库），不要勾选初始化 README，点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**，把本文件夹里的所有内容（`index.html`、`manifest.webmanifest`、`sw.js`、三个 `.png` 图标、`.nojekyll`）拖进去，点 **Commit changes**。
   > 注意：图标必须与其他文件**放在同一层**（不要建 `icons/` 子文件夹），否则主屏幕图标会显示不出来。
4. 仓库 **Settings → Pages** → *Build and deployment* → Source 选 **Deploy from a branch**，Branch 选 **main** + **/ (root)**，点 Save。
5. 等 1 分钟左右，页面顶部会出现网址：`https://<你的用户名>.github.io/xiaokucun/`。

## 在 iPhone 上使用

1. 用 **Safari** 打开 `https://<你的用户名>.github.io/xiaokucun/`。
2. 点底部分享按钮 → **添加到主屏幕** → 命名“我的小库存” → 添加。
3. 以后从主屏幕图标打开即可，全屏无浏览器地址栏；打开时自动检查提醒。

> ⚠️ 备份提醒：iOS Safari 在**长期（约 7 天以上）不访问**网页时可能清理本地存储。添加到主屏幕后风险会降低，但仍建议定期在「设置 → 导出 CSV」备份数据。
>
> ℹ️ 网页版无法在后台定时推送通知（这是系统限制，非应用问题）；打开应用时会自动刷新提醒，真正的后台定时推送需要做成原生 App。

## 备份与恢复（iPhone）

**备份**
1. 打开应用 → 「⚙️ 设置」→「导出 CSV（备份）」。
2. Safari 会下载文件，点下载图标 → **存储到「文件」**，建议存到 **iCloud 云盘**（换机也不丢）。
3. 设置页会显示「上次导出：X 天前」，方便你判断是否需要再备份一次。
4. 建议频率：每周一次，或在大量录入之后。

**恢复 / 换机迁移**
1. 打开应用 → 「⚙️ 设置」→「导入 CSV」→「📁 从「文件」选择 CSV 备份文件」，选中备份即可自动导入（也可以直接把内容粘贴到文本框）。
2. 注意：**导入是合并，不会清空现有数据**。如果想完全还原成备份时的样子，先「清空全部数据」再导入。
3. 导出文件里只有物品档案与批次信息，不含任何账号信息；请勿把个人备份 CSV 提交到公开仓库（`.gitignore` 已默认忽略 `*.csv`）。

> 提示：数据默认只存在这台手机的这个浏览器里。换手机、清理 Safari 数据、或长期不打开导致系统清理后，都需要用备份恢复。

## 更新应用

修改 `index.html` 后重新上传覆盖（网页界面再拖一次即可），或在本地：

```bash
git add -A
git commit -m "update app"
git push
```

GitHub Pages 会在一分钟内自动更新。手机上如仍显示旧版，下拉刷新或重开一次即可（Service Worker 采用网络优先策略）。

## 隐私

- 无后端、无账号、无埋点，数据只存在你的设备浏览器里。
- 导出的 CSV 由你自行保存，请勿把包含个人物品信息的备份文件上传到公开仓库。
